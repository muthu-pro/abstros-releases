# Abstros releases

Installers for **Abstros** (macOS 14 or later) and the feed its built-in updater reads.

- **Download:** the newest installer is under [Releases](https://github.com/muthu-pro/abstros-releases/releases/latest).
- **Updates:** once installed, Abstros updates itself (Abstros › Check for Updates…, or Settings › System › Updates).
- **Feed:** `https://muthu-pro.github.io/abstros-releases/appcast.xml`. Every installer is notarized by Apple, signed with a Developer ID Installer certificate, and signed again with the Abstros update key that the app checks before installing.

The source code isn't public; this repository only holds what's published.
